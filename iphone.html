PET Tool for iPhone

Makes the Productivity Entry Tool fit your iPhone screen in Safari.

Open this page on your iPhone

Scan with the iPhone camera, or send yourself this link.

Open this page in Safari

This only works in Safari. Chrome and other browsers on iPhone can't use add-ons. Copy this page's address and open it in Safari.

On an iPhone, PET squeezes into the narrow screen and the boxes overlap. This sets it up once so that every time you open PET in Safari, it skips the Continue in browser page and fits the screen by itself. It's free and takes about two minutes.

1

Get the free Userscripts app

An open-source Safari add-on that runs small scripts like this one.

Get Userscripts
2

Switch it on

  1. Open Settings → Apps → Safari → Extensions → Userscripts.
  2. Turn on Allow Extension.
  3. Set websites to Allow (choose All Websites if it asks).
  4. Open the Userscripts app once, then come back here.
3

Add the PET Tool script

  1. Tap the button below. A page of code opens; that's expected.
  2. Tap the menu button at the left of Safari's address bar (it shows aA on older iPhones).
  3. Tap Userscripts, then Install.
Add PET Tool script
4

Open PET in Safari

Open the Productivity Entry Tool the way you normally do and sign in. It fits the screen by itself.

  • Pinch to zoom in on the part you're filling in.
  • Turn the phone sideways for bigger text.
  • To switch it off: Safari menu → Userscripts → turn off PET Tool.
  • Updates arrive automatically.

Is it safe?

The script only runs on Power Apps (apps.powerapps.com) and only changes how the page fits the screen. It doesn't see, store or send your sign-in or your entries. You can read every line of it with the button in step 3.

No add-on wanted? The PET Fit page has a one-tap bookmark instead.
